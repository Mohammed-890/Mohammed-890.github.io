How I work

The same three habits run through every project on the map.

Beat a baseline first

Every model is compared with a simple rule. My first Ghost Bus model lost to one, so I simplified it until it won.

Test on data it hasn't seen

Time-based splits, held-out variants and evaluation sets, and every project says plainly what it can't do yet.

Check the numbers before sharing

Ghost Bus's first real day showed 46 ghost buses. 45 were duplicate timetable entries. I found it, fixed it and added a test.
